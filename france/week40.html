Bonjour ! 认识“我、你、他、她”

本周重点：s’appeler（叫……名字）、être（是）以及 je / tu / il / elle。
通过听、说、读、写，把这些表达真正用起来。

🇫🇷🎧🗣️
本周学习进度0 / 5

📖 1. 先学会这些表达

先看清楚是谁，再选择正确的人称和动词形式。点击 🔊 可以听法语发音。

第一组：s’appeler = 叫……名字
je → je m’appelle　　tu → tu t’appelles
il → il s’appelle　　elle → elle s’appelle
第二组：être = 是
je → je suis　　tu → tu es
il / elle → il est / elle est　　c’est = 这是 / 那是 / 这是……
人称代词：je 我　·　tu 你　·　il 他　·　elle 她
小对话：
— Tu t’appelles comment ?
— Je m’appelle Emma.

— Il s’appelle comment ?
— Il s’appelle Lucas.
这一部分学完了吗？

🎙️ 3. 口语训练

先听标准示范，再自己说。网页可以录下声音供你回放比较；录音只在当前浏览器中临时使用，不会上传。

任务 1：介绍自己：Je m’appelle + 你的名字.
任务 2：问对方名字：Tu t’appelles comment ?
任务 3：看见一个男孩，说：Il s’appelle …；看见一个女孩，说：Elle s’appelle …

至少练习三句话，再标记完成。

✍️ 4. 阅读 + 写作

先读句子，再根据人称选择正确形式。这里重点练习 je / tu / il / elle。

1. Emma 是女孩：_____ s’appelle Emma.

2. Je _____ Elsa.

3. 翻译成法语：你叫什么名字？

4. 翻译成中文：Il s’appelle Lucas.

5. 自己写两句：一句介绍自己，一句介绍“他”或“她”。

这道开放题不自动评分。写完后自己检查：有没有 je/il/elle？s’appelle 的形式是否正确？

阅读和写作完成后标记。
